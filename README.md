# pairwise-loudness-norm

同一段对白在游戏里正常，切到过场动画突然炸耳，接耳机又小得听不清：响度归一化按瞬时峰值，没有按积分响度算；门限只做绝对门限，没有相对门限，安静段落被拉高；多声道按单声道求和，5.1 的环绕声被算大；true peak 没有过采样，峰值超过 0 dBFS 被削；不同平台的目标 LUFS 不同，混音总线共用一套预设；过场动画和战斗音乐走不同总线，归一化各算各的；流式音频分块处理，块边界处响度跳变；动态范围压缩在归一化之后做，安静段又被压；设备切换采样率后积分窗口没重建，响度漂移；字幕/对白轨没有单独标记，被音乐掩盖；归一化缓存按文件路径，重新混音后仍用旧增益；实时监听和离线渲染的积分时间不同，结果不一致；多语言版本共用增益，日语对白比英语轻。audio/loudness_norm.py 是核心，tests/test_loudness_norm.py 15个红。要修的是：积分响度；双门限；多声道加权；true peak；平台预设；总线分组；块边界；压缩顺序；设备重建；对白轨；缓存版本；实时离线一致；多语言增益。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
